# Step-by-step Roadmap Auto-Split Hook project across all 3 programs
---

## OVERVIEW

You’re building:

* A **Uniswap v4 Hook** that splits LP fees automatically.
* A **Splitter smart contract** that receives & redistributes funds.
* A **Gasless Mini-App frontend** for deployment and visibility.
* All this runs on **Base chain**, is open-source, and can scale to users/teams.

---

## 🔁 Phase 1: Scaffold the Project

### 🔹 Step 1. Clone Scaffold-ETH-2 (Frontend + Contracts)

```bash
npx create-scaffold-eth@latest
cd scaffold-eth-2
```

This gives you:

* Working frontend (React, Wagmi, RainbowKit)
* Working smart contracts folder (Hardhat or Foundry)
* Hot reloading local dApp for Base testnet

---

## 🔩 Phase 2: Build Core Contracts

### 🔹 Step 2. Create `Splitter.sol`

* Extend or simplify OpenZeppelin’s `PaymentSplitter`
* Add:

  * `addPayee(address, uint256)` (for % splits)
  * `release(address)` (withdraw funds)
  * Optional: `createSplitter()` in factory style

👉 I’ll generate the starter code for this if needed.

---

### 🔹 Step 3. Deploy `Splitter.sol` Locally

```bash
npx hardhat deploy
```

* Write a script to deploy it with mock payees.
* Test with ETH or token payments.

---

## 🔥 Phase 3: Build & Test the Hook (Uniswap v4 Core)

### 🔹 Step 4. Fork [`uniswap/v4-core`](https://github.com/Uniswap/v4-core)

* Add your custom **hook**:

  * Name it `AutoSplitHook.sol`
  * In `beforeSwap` or `afterSwap`, forward X% fees to `Splitter.sol`

> Start with **simple hardcoded logic**, like:
> “Send 10% of collected fee to `Splitter.sol` address.”

---

### 🔹 Step 5. Integrate & Simulate Hook

* Use `v4-periphery` or Foundry to simulate swaps using your hook.
* Deploy to **Base Sepolia** once it’s tested.

---

## 🧪 Phase 4: Gasless Frontend App

### 🔹 Step 6. Build a Simple UI in Scaffold-ETH

* `CreateSplitter.tsx`: form where users enter wallet addresses + % → deploys Splitter.
* `Leaderboard.tsx`: display past split deployments with earnings.
* Show “Split revenue to team” and allow **claim payouts** via button.

---

### 🔹 Step 7. Add Gasless Support

* Integrate **Biconomy SDK** or **StackUp SDK**
* Enable:

  * Deploy Splitter contract without gas
  * Call `release()` without user paying gas

---

## 📡 Phase 5: Deploy & Submit

### 🔹 Step 8. Deploy to **Base Mainnet or Base Sepolia**

* Use Base documentation: [https://docs.base.org](https://docs.base.org)
* Register your contracts + frontend
* Make app public with a nice URL (e.g., Vercel or Netlify)
