## 🚀 Step-by-Step: What to Do

| Step | Task                                                                     | Resources                                                                                                             |
| ---- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 1️⃣  | Clone [`scaffold-eth-2`](https://github.com/scaffold-eth/scaffold-eth-2) | `npx create-scaffold-eth` or manual                                                                                   |
| 2️⃣  | Write `Splitter.sol` with `release()`, `addPayee()`                      | Use [OpenZeppelin’s PaymentSplitter](https://docs.openzeppelin.com/contracts/4.x/api/finance#PaymentSplitter) as base |
| 3️⃣  | Clone [`uniswap/v4-core`](https://github.com/uniswap/v4-core)            | Follow [Uniswap Hook Guide](https://uniswapv4.com/hooks)                                                              |
| 4️⃣  | Implement your `AutoSplitHook.sol`                                       | Start with simple `beforeSwap` logic → call `Splitter.sol`                                                            |
| 5️⃣  | Add gasless support in frontend                                          | Follow [Biconomy guide](https://docs.biconomy.io/) or [StackUp docs](https://docs.stackup.dev/sdk)                    |
| 6️⃣  | Add “Create Splitter” UI                                                 | Simple form → deploy → show contract address                                                                          |
| 7️⃣  | Add Leaderboard UI (read onchain txs)                                    | Read `event SplitCreated(...)` to populate                                                                            |
| 8️⃣  | Write tests for `Splitter.sol` + hook logic                              | Foundry/Hardhat unit + integration tests                                                                              |
| 9️⃣  | Deploy to **Base Sepolia**                                               | Start collecting metrics for Onchain Summer                                                                           |
| 🔟   | Submit to each program (guides below)                                    | I can help write those for you                                                                                        |
